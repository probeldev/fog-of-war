# 🌫️ Туман Войны

Мобильное приложение для исследования города. Вся карта скрыта туманом — ходи по городу и открывай новые территории!

## Описание

- **Карта покрыта туманом** — изначально вся карта белая
- **Ходишь — открывается** — GPS отслеживает перемещение и открывает область вокруг
- **Сохранение прогресса** — все открытые территории сохраняются
- **Статистика** — процент исследования, пройденное расстояние, время

## Технологии

- **Apache Cordova** — фреймворк для мобильных приложений
- **OpenStreetMap** — карты
- **Leaflet.js** — библиотека для работы с картами
- **Canvas API** — отрисовка тумана войны
- **localStorage** — сохранение прогресса

## Запуск для разработки

### Локальный сервер

```bash
cd www
python3 -m http.server 8080
```

Откройте http://localhost:8080 в браузере.

> **Примечание:** Для работы геолокации нужен HTTPS или localhost. В браузере GPS может не работать — используйте мобильное устройство.

## Сборка мобильного приложения

### Установка Cordova

```bash
npm install -g cordova
```

### Добавление платформ

```bash
# Android
cordova platform add android

# iOS
cordova platform add ios
```

### Сборка

```bash
# Android
cordova build android

# iOS
cordova build ios
```

### Запуск на эмуляторе

```bash
# Android
cordova run android

# iOS
cordova run ios
```

## Использование

1. **Запустите приложение**
2. **Нажмите "Начать исследование"** — разрешите доступ к геолокации
3. **Ходите по городу** — карта открывается вокруг вас
4. **Настройки** — можно изменить радиус открытия и прозрачность тумана
5. **Экспорт/Импорт** — сохраняйте прогресс в файл

## Настройки

- **Радиус открытия** (10-200 м) — насколько большая область открывается вокруг вас
- **Прозрачность тумана** (50-100%) — насколько плотным будет туман
- **Экспорт прогресса** — сохранить в JSON файл
- **Импорт прогресса** — загрузить из JSON файла

## Особенности

- GPS обновляется каждую секунду
- Прогресс автоматически сохраняется каждые 10 секунд
- Фильтр шума GPS — движения менее 5 метров не учитываются
- Работает в фоновом режиме (при разрешении ОС)

## Разрешения

Приложение запрашивает:
- `ACCESS_FINE_LOCATION` — точная геолокация
- `ACCESS_COARSE_LOCATION` — приблизительная геолокация
- `ACCESS_BACKGROUND_LOCATION` — геолокация в фоновом режиме (Android)
